# Banana Sky Rescue – Save the Falling Animals

## Project Overview

Banana Sky Rescue is a 2D web-based rescue game in which players control a panda piloting a hot-air balloon. Players rescue animals from floating islands, avoid obstacles, and solve Banana API puzzles to restore energy.

## Technologies

- JavaScript and Phaser – 2D gameplay
- Java Spring Boot – Backend services
- MySQL – Database
- HTML and CSS – Web interface
- Git and GitHub – Version control

## Main Features

- Player registration and email verification
- Secure login and authentication
- Four themed game worlds
- Animal pickup and delivery
- Obstacles and Banana Energy
- Banana API puzzle integration
- Saved progress and leaderboard

## Software Development Concepts

1. Version Control
2. Event-Driven Programming
3. Interoperability
4. Virtual Identity
